# Динамика курса рубля к USD, EUR и CNY (2022–2026)

Pet-проект по анализу данных: курсы валют загружаются напрямую через официальный XML-API Банка России (cbr.ru) — без готового датасета с Kaggle.

## Вопросы исследования

1. Как менялись курсы USD, EUR и CNY к рублю за 2022–2026?
2. В какие периоды волатильность была максимальной?
3. Насколько синхронно двигаются разные валюты?
4. Как менялась роль юаня на фоне ухода западных валют?

## Что внутри

`cbr_currency_analysis.ipynb` — загрузка данных через API, анализ волатильности, корреляций между валютами, поиск и объяснение резких скачков курса.

## Ключевые выводы

- Волатильность всех трёх валют в 2022 году была примерно в 3 раза выше, чем в 2023–2026 (2.5–2.6% против 0.8–1% в день).
- USD и CNY коррелируют по дневным изменениям сильнее (0.93), чем USD и EUR (0.91) — курсы движутся скорее синхронно из-за общего фактора силы/слабости рубля, а не независимо друг от друга.
- Волатильность юаня не оказалась ниже волатильности доллара ни в один год — вопреки ожиданиям, юань не стал более "спокойной" валютой.
- Самые резкие скачки курса (+8–12% за день) пришлись на начало марта 2022 — сразу у всех трёх валют одновременно.

## Как запустить

    pip install requests pandas matplotlib
    jupyter notebook cbr_currency_analysis.ipynb

Для загрузки данных нужен доступ в интернет — ноутбук делает запросы напрямую к API ЦБ РФ при запуске.
